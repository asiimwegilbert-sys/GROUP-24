# Project Plan

1. Implement and test `Vector` and `Matrix` foundations.
2. Add Gaussian elimination, determinant, and inverse.
3. Add LU, Cholesky, QR, and Gram-Schmidt.
4. Add Jacobi, Gauss-Seidel, and power iteration.
5. Add interpolation and integration methods.
6. Add least-squares and eigenvalue methods.
7. Implement two-body RK2/RK4 satellite propagation.
8. Replace every placeholder test and example with meaningful cases.
9. Update the README and weekly reports in the group's own words.

Decide as a group: units, tolerances, exception types, singular-matrix behavior, and result formats.
